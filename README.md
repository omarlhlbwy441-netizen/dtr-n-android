## 🔥 الميزات الأساسية والأنظمة المدمجة

### 1. 🧠 محرك التفكير والتحليل العميق (Thinking & Reasoning Engine)
عند إرسال أي سؤال أو طلب بناء أو إصلاح، يقوم النظام بالمرور عبر أربع مراحل تسلسلية:
- **1. التفكير والمراجعة (Thinking & Reviewing):** مراجعة سياق الشفرة والطلبات بدقة.
- **2. التخطيط والهيكلة (Planning):** اختيار بنية الملفات وقواعد البيانات والمكونات المناسبة.
- **3. التصحيح والتنفيذ (Correction & Execution):** كتابة وتوليد الأكواد النظيفة الكاملة بدون اختصارات.
- **4. الرد التقني المباشر (Direct Output):** تقديم الإجابة بأسلوب متفاعل وشامل.

### 2. 🧠 الذاكرة طويلة المدى (Long-Term Memory Persistence)
- ربط المحادثات بقاعدة بيانات محليّة سريعة وآمنة (**Room Database**).
- إرفاق سياق المحادثة السابقة تلقائياً مع كل طلب لمنع فقدان الذاكرة أو نسيان المشاريع المفتوحة.

### 3. 📷 تحليل الصور والمرفقات (Vision & Attachments Engine)
- دعم قراءة وتحليل المستندات والصور والمخططات البرمجية فورياً.

### 4. 📺 شاشة العرض والمعاينة المباشرة (Live Preview & Web Container)
- إمكانية معاينة الواجهات البرمجية، الألعاب، المواقع، والفيديوهات المباشرة بضغطة زر.
- إصلاح وتفعيل زر **"زيارة الرابط"** لفتح الروابط والمعاينات فورياً.

### 5. 🎙️ النظام الصوتي والمكالمات الحية (Live Voice Session)
- دعم قراءة النصوص صوتياً باللغة العربية وإجراء مكالمات تفاعلية حية.

## 🛠️ المعمارية البرمجية (Architecture)

```
app/src/main/java/com/example/
├── data/
│   ├── api/
│   │   └── GeminiClient.kt          # محرك الذكاء الاصطناعي والاستجابات الهجينة
│   ├── local/
│   │   ├── AppDatabase.kt           # قاعدة بيانات Room
│   │   ├── ChatDao.kt               # عمليات استعلام المحادثات
│   │   └── ChatMessageEntity.kt     # كيانات حفظ الذاكرة طويلة المدى
│   └── model/
│       └── AgentModels.kt           # نماذج بيانات المحادثات والوكلاء
├── ui/
│   ├── components/
│   │   ├── ChatMessageItem.kt       # فقاعات الرسائل وأزرار النسخ والمعاينة
│   │   ├── InputBottomBar.kt        # شريط الإدخال ورفع المرفقات
│   │   ├── LivePreviewDisplaySheet.kt # شاشة المعاينة الحية
│   │   └── TopHeaderBar.kt          # الشريط العلوي بأسلوب Dark Sky Blue
│   ├── theme/
│   │   ├── Color.kt                 # الألوان الأساسية
│   │   └── Theme.kt                 # إعدادات Jetpack Compose Theme
│   └── viewmodel/
│       └── RepoAgentViewModel.kt    # إدارة الحالة والتفاعل مع قاعدة البيانات وGemini
└── MainActivity.kt                  # الواجهة الرئيسية للتطبيق
```
